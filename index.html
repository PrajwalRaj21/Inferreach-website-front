// how it works

Five stages.
One pipeline.

From raw CSV to booked meeting — every step is automated, logged, and yours to control.

01

Lead Import

Upload a CSV of target prospects. We validate, deduplicate, and store everything into a structured database ready for enrichment.

postgres
02

Email Enrichment

Missing emails are found via Hunter.io. Every lead is scored and validated before it ever enters a sequence.

hunter.io
03

AI Personalization

Claude runs inference on each lead to generate a unique, context-aware opening line — no copy-paste templates.

claude api
04

Delivery

Emails go out via Resend with daily rate limits and full send logging. Deliverability is built in, not bolted on.

resend
05

Automated Follow-ups

Day 3 and day 7 follow-ups run on schedule. Replied leads are automatically skipped. Everything is logged.

scheduler
